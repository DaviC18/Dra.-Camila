# Site Dra. Camila Mattje — pacote de planejamento

Landing page single page para a Dra. Camila Mattje (dentista 24h, Barra Mansa — RJ).

## O que tem aqui
| Arquivo | Para quê |
|---|---|
| `CLAUDE.md` | Instruções e regras para a IA que vai desenvolver |
| `docs/spec.md` | Especificação: objetivo, stack, design system, seções, animações, SEO, critérios de aceite |
| `docs/plan.md` | Plano de implementação em 7 fases (0–6), com skills por fase |
| `docs/content.md` | Todo o conteúdo levantado do Google Maps e Instagram |

## Como usar
1. Extraia este zip na raiz do projeto (pasta vazia).
2. Garanta que as skills **taste-skill**, **impeccable** e **gsap-skills** estão instaladas.
3. Peça à IA: "Leia o CLAUDE.md e execute o docs/plan.md a partir da Fase 0."

## Stack
Vite · React · TypeScript · Tailwind CSS v4 · GSAP (+ ScrollTrigger, SplitText) · shadcn/ui · React Bits · lucide-react
